# InstaLab (ಇನ್‌ಸ್ಟಾಲ್ಯಾಬ್) — Explore Science by Doing

A mobile-first, bilingual Kannada/English science-learning website. It is static and suitable for GitHub Pages.

## Files
- `index.html` — page shell and navigation
- `styles.css` — responsive layout, accessible controls, print rules
- `app.js` — bilingual content, interactive simulations, quiz, notes and section rendering
- `instalab-logo.png` — logo/favicon
- `README.md` — this guide

## Run locally
Open `index.html` in a modern browser. For best compatibility, run a small local static server or use GitHub Pages.

## Publish to GitHub Pages
1. Upload all five files to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Select the deployment branch and `/ (root)` folder.
4. Save and wait for the deployment workflow to finish.
5. Open the Pages URL and hard-refresh if an older version is cached.

## Important honesty notes
- This build includes 12 interactive educational models, 16 equipment guides, 10 scientist summaries, 15 knowledge topics, 10 quiz questions, 10 starter projects and 16 example career profiles.
- The science models are simplified educational illustrations, not substitutes for real measurements or supervised laboratory experiments.
- The videos/resources section links to external sources; it does not claim that every individual video has been independently reviewed.
- The tutor is a small offline keyword-based answer bank, **not a live AI model**.
- The science updates section is evergreen science-literacy content, **not a live news feed**.
- Notes, observations and quiz results are saved in the current browser's `localStorage`. Clearing browser/site data will remove them.
- No textbooks are included, hosted or linked. Worksheets are original supplemental activities and links point to public science resources.

## Accessibility and safety
Keyboard-friendly buttons, visible focus styles, reduced-motion support, a skip link, modal close behavior and responsive mobile navigation are included. Always follow local lab rules, use adult/teacher supervision where appropriate, and never use mains electricity for school experiments.
