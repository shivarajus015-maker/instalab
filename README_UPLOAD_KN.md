InstaLab website upload instructions (Kannada)

ಈ package ನ index.html ಹೊಸ single-file website ಆಗಿದೆ.

GitHub ಗೆ upload ಮಾಡುವ ವಿಧಾನ:
1. ನಿಮ್ಮ repository ತೆರೆಯಿರಿ: https://github.com/shivarajus015-maker/instalab
2. Add file > Upload files ಕ್ಲಿಕ್ ಮಾಡಿ.
3. ಈ package ಒಳಗಿನ index.html ಫೈಲ್ ಅನ್ನು ಆಯ್ಕೆಮಾಡಿ.
4. GitHub ಕೇಳಿದರೆ existing index.html ಅನ್ನು replace/overwrite ಮಾಡಲು ಒಪ್ಪಿ.
5. ಕೆಳಗೆ commit message ಬರೆಯಿರಿ: Update InstaLab interactive science website
6. Commit changes ಕ್ಲಿಕ್ ಮಾಡಿ.
7. GitHub Pages update ಆಗಲು ಸ್ವಲ್ಪ ಸಮಯ ಕಾಯಿರಿ; ನಂತರ https://shivarajus015-maker.github.io/instalab/ ತೆರೆಯಿರಿ.

ಗಮನಿಸಿ:
- ಹಳೆಯ index.html ನ backup ಇಟ್ಟುಕೊಳ್ಳಿ.
- app.js, README.md ಮತ್ತು instalab-logo.png ಅನ್ನು ಅಳಿಸಬೇಡಿ.
- ಈ ಹೊಸ index.html self-contained ಆಗಿದೆ; ಇದರ ಮುಖ್ಯ features ಗೆ app.js ಅಗತ್ಯವಿಲ್ಲ.
- Upload ಮಾಡಿದ ನಂತರ website ಸರಿಯಾಗಿ ತೆರೆಯುತ್ತದೆಯೇ ಮತ್ತು simulations ಕೆಲಸ ಮಾಡುತ್ತವೆಯೇ ಪರೀಕ್ಷಿಸಿ.
